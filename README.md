# 🏋️‍♂️ Personal Trainer — Aplicativo Mobile & Web

Aplicativo completo para Personal Trainers e Alunos de Musculação, construído com **React Native**, **Expo Router**, **Supabase** (PostgreSQL na nuvem) e **Tailwind/Design System Dark**.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fsamuelcomprasonline-crypto%2Fpersonal-trainer)

---

## ⚡ Funcionalidades

- **👤 Modo Aluno & Treinador**: Diferenciação completa com login inicial e código individual.
- **📋 Ficha de Treino Interativa**: Séries, cargas progressivas, substituição de exercícios e cronômetro de descanso interativo com alertas táteis/sonoros.
- **📄 Prontuário de Avaliação Biomecânica**: Leitura automática de balança clínica (OCR), bioimpedância, dobras cutâneas, fotos comparativas e emissão de laudo em PDF formato A4.
- **💰 Gestão Financeira do Personal**: Fluxo de caixa em tempo real, cálculo do valor da hora-aula efetiva e cobrança via WhatsApp com chave PIX.
- **☁️ Sincronização em Nuvem (Supabase)**: Banco de dados relacional PostgreSQL e Storage para fotos com funcionamento híbrido offline-first.
